        Technical Details

        Finds the daily r/ColorPuzzleGame post on Reddit, scrapes the board, and solves it, using a search algorithm shared between a Python pipeline and the live page it publishes to.

        Each morning, a scheduled script retrieves the daily puzzle, reads the board with Playwright, executes the solver and saves the results to JSON, then pushes it, triggering a GitHub Actions deploy to this page.

        The solver implements an A* algorithm to return a solution with the fewest possible moves. It's written once in TypeScript. The Python pipeline calls the solver through a small Node CLI. The same code is reached by user input; client code calls it with an 8-second limit.
